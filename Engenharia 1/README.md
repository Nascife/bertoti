# Atividades


1 - O que eu entendi com o texto 1:
O texto diferencia a programação em si da Engenharia de Software. Um programador busca fazer o código funcionar hoje. Já a engenharia de software busca aplicar a programaçao com mais rigor e responsabilidade como nas outras engenharias e busca entender o funcionamento completo de um sistema

2 - O que eu entendi com o texto 2:

A engenharia de software se preocupa bastante com como o codigo irá funcionar no futuro, e não apenas fazer o codigo rodar no momento de desenvolvimento. Além disso como escolher as ferramentas certas e o que perdemos e o que ganhamos com o uso de ferramentas diferentes, o chamado Trade-Off.

3 - 3 exemplos de Trade-Off:
  1. Segurança vs Fácil Usabilidade.
    Um programa que que muitos fatores de autenticaçao pode vir a não ser tão simples para utiliza-lo, enquanto um sistema de fácil acesso pode comprometer sua segurança.
  2. Performance vs Legibilidade.
    Um programa muito otimizado para ser mais rápido pode não ser tao fácil de entender quanto um programa mais simples mas que o seu tempo te processamento é maior
  3. Monólito vs. Microsserviços.
    É possível criar um sistema em uma única aplicação e ser mais simples para entender e modificar, mas pode ser dificil para escalar e manter conforme ele cresce. Já um sistema com varios micro serviços oferece maior escalabilidade mas fica mais complexo.
